# 实施计划：咖啡社交订阅电商平台 (纯线上原型版)

## 1. 背景与目标
基于提供的详细交互概览，本项目旨在将现有的 `sheep` Next.js 应用转型为一个专注于咖啡领域的社交订阅电商平台。
**核心目标**：采用前端原型优先（Mock API + Zustand 状态管理）的策略，快速构建并验证这四大核心模块（社交发现、商品订阅、物流凑单、用户留存）的 UI 和交互逻辑。

## 2. 技术栈与架构选型
- **框架**: Next.js 15 (App Router) + React 19
- **样式**: Tailwind CSS + Framer Motion (用于页面过渡和微交互，如口味测试动画)
- **状态管理**: Zustand (用于跨组件共享购物车、用户口味画像、订阅状态)
- **组件库**: 基于现有极简黑白风格（Ulinki Redesign）开发定制化无头组件 (Radix UI 或类似方案辅助)。
- **图表与可视化**: Recharts (用于风味雷达图)
- **海报生成**: html2canvas + 纯前端 Canvas 绘制

## 3. 分阶段实施路径

### 阶段一：基础设施与 Mock 数据搭建 (Foundation)
- 安装必要的依赖：`zustand`, `framer-motion`, `recharts`, `lucide-react` (图标)。
- 设计全局状态管理：
  - `useCartStore`: 购物车逻辑（支持单次购买和周期订阅）。
  - `useUserStore`: 用户画像（包含口味测试结果）。
- 构建 Mock API 和数据结构：
  - 咖啡豆数据模型（包含风味雷达数据、烘焙度、处理法）。
  - 社区笔记流数据。
  - 物流轨迹节点数据。

### 阶段二：首页与社交发现交互 (Module 1)
- **口味测试引导**: 实现首次访问拦截（基于 `localStorage`），弹出交互式问答弹窗，使用 Framer Motion 实现平滑翻页，最后生成口味画像（如“果香爱好者”）。
- **社区信息流**: 在 `app/page.tsx` 实现瀑布流布局，展示图文笔记卡片。
- **一键加购浮窗**: 笔记卡片底部集成悬浮加购按钮，点击弹出 Half-sheet (底部半屏弹窗) 选择 SKU。

### 阶段三：商品详情与订阅交互 (Module 2)
- **可视化风味参数**: 集成 Recharts 绘制多维风味雷达图（酸度、醇厚度等）。
- **订阅制切换面板**: 在详情页右侧/底部构建购买面板，实现“单次购买”与“周期订阅”的 Tab 切换，联动价格计算和配送频率选择。
- **研磨度辅助**: SKU 选择器中加入图片 Tooltip 或展开项，展示意式细粉/手冲中粉等实拍对比图。

### 阶段四：购物车与物流交互 (Module 3)
- **智能凑单提示**: 购物车顶部添加进度条组件，实时计算当前金额距包邮门槛（如 199 元）的差值。
- **智能地址解析**: 模拟地址解析逻辑，提供大文本框，使用正则提取姓名、电话和地址片段填入表单。
- **全链路物流追踪**: 在订单详情页实现垂直时间轴 (Timeline) 组件，结合静态地图背景展示物流节点。

### 阶段五：个人中心与留存交互 (Module 4)
- **可视化订阅日历**: 在个人中心引入日历视图，标注下次发货日期，提供管理订阅操作的快捷入口。
- **冲煮笔记发布器**: 创建表单页面，内置参数模板（水温、粉水比），降低分享门槛。
- **专属开箱海报**: 用户收货后，基于 DOM 节点使用 `html2canvas` 生成带有专属卡面、标签和昵称的分享海报图片。

## 4. 验证与验收
- 测试所有状态切换（订阅 vs 单次购买）是否正确计算金额。
- 验证口味测试是否能正确保存至全局状态并在推荐中生效。
- 确保移动端和桌面端（尤其是瀑布流和底部弹窗）的响应式体验流畅。
