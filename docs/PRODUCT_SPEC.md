# 咖啡社交订阅电商平台 UI 交互概览 (纯线上版)

## 1. 首页与社交发现交互

- **口味测试引导**：新用户首次进入时，弹出交互式趣味测试（如水果偏好、甜度偏好），完成后自动生成专属风味画像并推荐对应咖啡豆组合。
- **社区信息流展示**：首页以图文/短视频笔记为主（类似小红书瀑布流），展示用户的冲煮心得、设备评测和开箱分享。
- **内容一键加购**：在阅读笔记文章时，底部常驻“笔记同款商品”浮窗或卡片，点击可直接调起 SKU 弹窗加入购物车，无需中断阅读体验。

## 2. 商品详情与订阅交互

- **可视化风味参数**：详情页直观展示酸度、醇厚度、甜感等维度的风味雷达图，以及清晰的烘焙度和处理法图标。
- **订阅制切换面板**：购买操作区提供“单次购买”与“周期订阅”双 Tab。切换至“周期订阅”时，展开配送频率选择器（如每2周/每月），并自动更新为订阅特惠价。
- **研磨度辅助对比**：在选择咖啡豆的研磨度 SKU 时，选项旁提供实拍的颗粒粗细对比图（如意式细粉、手冲中粉），辅助新手决策。

## 3. 购物车与全国物流交互

- **智能凑单与运费提示**：购物车内常驻进度条，实时计算咖啡豆与周边器具的组合金额，提示距离全国包邮门槛还差多少。
- **智能地址解析**：由于纯线上发货，新增地址时提供大文本框，支持用户直接粘贴完整的收件信息，系统自动解析填入姓名、电话和省市区街道。
- **全链路物流追踪**：订单详情页接入快递物流接口，以时间轴结合地图的形式，展示包裹从“烘焙工坊发货”到“签收”的完整轨迹。

## 4. 个人中心与留存交互

- **用户注册与身份验证**：集成 Supabase Auth，支持邮箱/密码注册登录及 GitHub 第三方登录。登录后用户可同步订阅状态、保存购物车及管理冲煮笔记。
- **可视化订阅日历**：在“我的订阅”模块提供日历视图，清晰展示下一次发货的预计时间，并支持快捷点击“修改下期口味”、“推迟发货”或“跳过本期”。
- **冲煮笔记发布器**：内置结构化的发布模板，引导用户填写入门级参数（如：使用器具、水温、粉水比），降低分享门槛。
- **专属开箱海报**：用户确认收货后，系统自动生成包含所购咖啡豆卡面设计、风味标签和用户昵称的精美海报，方便一键分享至外部社交平台。
